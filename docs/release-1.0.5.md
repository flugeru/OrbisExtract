# OrbisExtract 1.0.5

## Português (Brasil)

- Selecione vários PKGs para extrair jogos independentes em paralelo. Para aplicar updates, inclua a base na mesma seleção. Os updates compatíveis são aplicados em ordem de versão.
- A leitura em blocos usa buffers reutilizáveis para sobrepor leitura, descriptografia e gravação de arquivos grandes.
- A prévia mostra título, versão, Content ID e arte. Se o PKG não tiver imagem utilizável, o app busca no Wikimedia Commons e exibe os créditos quando encontra uma correspondência.
- O seletor acompanha o tema do app, a capa ganhou moldura, a barra de progresso só aparece durante a extração e o log preenche o cartão.
- O aplicativo e o instalador Windows exibem a licença GPL-3.0-only.

Updates delta binários ficam fora da aplicação automática. No Android, a extração em lote exige um provedor de armazenamento que permita renomear pastas.

## English

- Select multiple PKGs to extract independent games in parallel. Include the base game to apply compatible updates in version order.
- Reusable buffers overlap reading, decryption and writing for large files.
- The preview shows the title, version, Content ID and artwork. When the PKG has no usable artwork, the app searches Wikimedia Commons and credits any match.
- The package picker follows the app theme, artwork has a frame, progress appears during extraction and the log fills the card.
- The app and Windows installer display the GPL-3.0-only license.

Binary delta updates are outside the automatic update support. Android batch extraction requires a storage provider that can rename folders.
