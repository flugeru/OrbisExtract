Suporte do OrbisExtract

Tem uma dúvida ou encontrou um problema? O projeto é mantido por flugeru e recebe relatos pelo GitHub. Você pode ler os chamados públicos sem uma conta; abrir um novo chamado exige login no GitHub.

Falar com o projeto

Use o canal oficial para problemas no app, dúvidas sobre compatibilidade e solicitações de privacidade.

Abrir chamado no GitHub

Chamados são públicos. Não anexe jogos, PKGs, chaves, senhas, nomes privados de pastas ou dados pessoais. Para uma solicitação de privacidade, comece descrevendo apenas o assunto.

Como relatar um problema

  • Informe a versão do OrbisExtract e a origem da instalação: GitHub ou, quando disponível, Google Play.
  • Informe o sistema, sua versão e o modelo do dispositivo, se relevante.
  • Descreva o que fez, o que esperava e o que aconteceu.
  • Se compartilhar um log ou captura, remova dados pessoais, nomes e caminhos privados. Não envie o próprio PKG.

Antes de repetir uma extração com falha, confira o espaço livre e as permissões de acesso. Preserve os arquivos originais e verifique qualquer saída parcial.

Downloads e atualizações

Consulte a última release publicada e suas notas. Os builds de desenvolvimento são destinados a testes e podem diferir da versão publicada.

Em APKs Android, uma assinatura diferente impede a atualização por cima. Não desinstale o app sem preservar os dados locais que deseja manter. O canal Play está em preparação e a chave de envio não torna os APKs da Play e do GitHub automaticamente intercambiáveis.

Privacidade e dados locais

Para solicitar esclarecimentos sobre dados ou direitos de privacidade, use o mesmo canal oficial, sem expor dados pessoais no chamado inicial. O projeto não possui um servidor com o conteúdo dos seus PKGs. Você também pode enviar uma solicitação privada para fluugell@gmail.com. Dados locais devem ser removidos no próprio dispositivo; arquivos extraídos nas pastas escolhidas precisam ser apagados separadamente.

Veja a Política de Privacidade para retenção, serviços externos e formas de exclusão. Os Termos de Uso esclarecem a licença e as limitações operacionais.

OrbisExtract Support

The project is maintained by flugeru. Read existing issues or open a GitHub support issue for bugs, compatibility questions or privacy inquiries. Reading public issues does not require an account; opening one requires GitHub sign-in. For a private inquiry, email fluugell@gmail.com. Community support has no guaranteed response time.

What to include

Share the app version and installation source, operating system/version, relevant device model, reproduction steps, expected result and actual result. Remove personal data and private filenames/paths from logs and screenshots. Never attach games, PKGs, keys or passwords. For privacy requests, describe only the topic in the initial public message.

Downloads and updates

Use the latest official release and its notes. Development builds are for testing and can differ. Android APK updates need a compatible signature; preserve local data before uninstalling. Play publication is being prepared. Upload signing does not make Play APKs and legacy GitHub APKs interchangeable.

Data and privacy

The project has no server holding your PKG contents. Local app data must be removed on your device, and extracted outputs separately in your chosen folders. See the Privacy Policy and Terms.
