The project is maintained by flugeru. Read existing issues or open a GitHub support issue for bugs, compatibility questions or privacy inquiries. Reading public issues does not require an account; opening one requires GitHub sign-in. For a private inquiry, email fluugell@gmail.com. Community support has no guaranteed response time.

What to include

Share the app version and installation source, operating system/version, relevant device model, reproduction steps, expected result and actual result. Remove personal data and private filenames/paths from logs and screenshots. Never attach games, PKGs, keys or passwords. For privacy requests, describe only the topic in the initial public message.

Downloads and updates

Use the latest official release and its notes. Development builds are for testing and can differ. Android APK updates need a compatible signature; preserve local data before uninstalling. Play publication is being prepared. Upload signing does not make Play APKs and legacy GitHub APKs interchangeable.

Data and privacy

The project has no server holding your PKG contents. Local app data must be removed on your device, and extracted outputs separately in your chosen folders. See the Privacy Policy and Terms.
