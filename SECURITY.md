# Security policy

**[English](#english)** · **[Português (Brasil)](#português-brasil)**

## English

Please check the [latest published release](https://github.com/flugeru/OrbisExtract/releases/latest) when reporting a vulnerability. Development builds and older releases are not guaranteed to receive fixes.

Use [GitHub's private vulnerability reporting form](https://github.com/flugeru/OrbisExtract/security/advisories/new). Include the affected version and platform, the impact, and enough detail to investigate. Do not post unresolved vulnerabilities in public issues. Do not send game packages, private keys or personal data. If a sample is necessary, use a minimal synthetic file.

For ordinary bugs, see the [contribution guide](CONTRIBUTING.md).

## Português (Brasil)

Ao relatar uma vulnerabilidade, confira a [última versão publicada](https://github.com/flugeru/OrbisExtract/releases/latest). Builds de desenvolvimento e versões antigas não têm garantia de correções.

Use o [formulário privado de vulnerabilidades do GitHub](https://github.com/flugeru/OrbisExtract/security/advisories/new). Informe a versão e plataforma afetadas, o impacto e os detalhes necessários para investigar. Não publique vulnerabilidades ainda não corrigidas em issues públicas. Não envie pacotes de jogos, chaves privadas ou dados pessoais. Se precisar incluir um exemplo, use um arquivo sintético mínimo.

Para bugs comuns, consulte o [guia de contribuição](CONTRIBUTING.md).
